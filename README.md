# ХимТест — химия по шагам

Учебный сайт на HTML, CSS и JavaScript без фреймворков, сборки и внешних зависимостей. Готовы 12 тем для 6–11 классов: по 25 вопросов, всего 300. При запуске выбираются 20 случайных вопросов. Тренажёр не заменяет учебник или проверку знаний учителем.

## Как открыть

Публичный сайт после публикации открывается с телефона и ноутбука по обычной ссылке: посетителям не нужны установка, регистрация или локальный сервер.

Для проверки на своём компьютере откройте терминал в папке `himtest-v2` и выполните:

```sh
python3 -m http.server 8792 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8792. Остановка сервера: Ctrl+C. Если порт занят, замените 8792 другим свободным портом.

Открытие index.html двойным щелчком не поддерживается: браузер ограничивает чтение отдельных ES-модулей и JSON по протоколу file://. Это согласованное уточнение первоначального задания.

## Как устроен проект

- `index.html` — основная разметка, диалог завершения и подключение файлов.
- `css/styles.css` — оформление, мобильная версия и тёмная тема.
- `js/app.js` — загрузка банка, перемешивание, таймер, переходы и результаты.
- `data/topics.json` — каталог тем. Записи без `file` показываются как готовящиеся.
- `data/questions/` — отдельный JSON-массив для каждой темы.
- `qa/` — проверки и материалы демонстрации; для хостинга не требуются.

## Как добавить вопрос

Откройте JSON нужной темы и добавьте объект в массив. Между соседними объектами нужна запятая; после последнего её быть не должно. Пример:

```json
{
  "id": "grade-6-substances-026",
  "grade": 6,
  "topic": "grade-6-substances",
  "text": "Что является веществом?",
  "options": ["Медь", "Стакан", "Ложка", "Гвоздь"],
  "correctIndex": 0,
  "explanation": "Медь — вещество. Остальные варианты называют физические тела."
}
```

`id` должен быть уникальным, `topic` должен совпадать с идентификатором темы в каталоге. Нужны ровно четыре разных варианта. `correctIndex` — номер правильного варианта, начиная с нуля: 0, 1, 2 или 3. В пояснении используйте 1–3 понятных предложения.

Формулы записывайте обычным текстом с Unicode-индексами: H₂O, CO₂, Ca(OH)₂. HTML-теги не нужны и не исполняются. После добавления вопроса обновите `count` в каталоге тем.

## Как добавить тему

1. Создайте JSON-файл в `data/questions/` по примеру существующих банков. Желательно минимум 25 вопросов.
2. В `data/topics.json` добавьте запись или дополните готовящуюся тему:

```json
{
  "id": "grade-7-basics",
  "grade": 7,
  "title": "Первоначальные химические понятия",
  "description": "Кратко опишите, что ученик повторит в этой теме.",
  "icon": "⚗",
  "count": 25,
  "file": "./data/questions/grade-7-basics.json"
}
```

3. В вопросах используйте такой же `topic` и соответствующий `grade`. Код менять не нужно.
4. Обновите страницу и пройдите тест. Если JSON некорректен, сайт покажет сообщение об ошибке; подробности доступны в консоли браузера.

## Правила теста

Из банка выбираются до 20 вопросов без повторений. Вопросы и варианты перемешиваются отдельно при каждом запуске. Время — 20 минут. Ответ можно изменить до завершения; пропуски считаются ошибками. Таймер использует время окончания, поэтому уход в другую вкладку не останавливает отсчёт. Последние две минуты выделены цветом; скринридер получает отдельное предупреждение.

Оценки: «5» от 85%, «4» от 65%, «3» от 45%, иначе «2». Если вопросов меньше 20, результат вычисляется от фактического количества. Разбор содержит все ошибки и пропуски. Обновление или закрытие страницы сбрасывает прохождение; браузер может предупредить о несохранённых ответах.

Никакие ответы, имена, результаты или персональные данные не сохраняются и не отправляются. Аналитики, внешних шрифтов и cookies в коде нет. Хостинг может вести собственные технические журналы обращений.

## Как опубликовать на GitHub Pages

1. Загрузите **содержимое** `himtest-v2` в корень репозитория (например, существующего `AleshqqaM/himtest`). В корне должны оказаться `index.html`, папки `css`, `js` и `data`. Перед обновлением сохраните старую версию или используйте историю GitHub для возврата.
2. В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки `main`, папка `/ (root)`.
3. Дождитесь успешного развёртывания и откройте выданную GitHub Pages ссылку. У существующего репозитория адрес сохранится: https://aleshqqam.github.io/himtest/.
4. Проверьте ссылку на отдельном телефоне, желательно через мобильную сеть. Для посетителей локальный сервер не нужен.

В GitHub можно использовать **Add file → Upload files** и загрузить папки вместе с файлами. Загрузка одного `index.html` недостаточна: ему нужны CSS, JS и JSON.

## Как опубликовать на Netlify

Загрузите папку сайта через ручную публикацию Netlify или подключите репозиторий. Команду сборки оставьте пустой; папка публикации — корень сайта (или `himtest-v2`, если он лежит внутри другого репозитория). Используйте выданную публичную ссылку.

## Проверки

Для проверки структуры банка и основной логики, если установлен Node.js 22 или новее:

```sh
node qa/check.mjs
```

Node.js нужен только разработчику для этой проверки, посетителям он не требуется.

Перед публичным обновлением проверьте: оба теста, изменение ответа при возврате, завершение с пропусками, полный правильный результат, автоматическое завершение по таймеру, отсутствие горизонтальной прокрутки и ошибок в консоли.

## Учебное содержание

Доступны следующие темы (по 25 вопросов в каждой):

- 6 класс: «Вещества и смеси»; «Физические и химические явления».
- 7 класс: «Первоначальные химические понятия»; «Атомы, молекулы и элементы».
- 8 класс: «Основные классы неорганических соединений»; «Периодический закон и строение атома».
- 9 класс: «Металлы и неметаллы»; «Электролитическая диссоциация и ионный обмен».
- 10 класс: «Углеводороды»; «Кислородсодержащие органические соединения».
- 11 класс: «Общая химия и ОВР»; «Неорганическая химия и взаимосвязи веществ».

Для 6–7 классов это пропедевтика: самостоятельный предмет «Химия» в основной школьной программе начинается позже. Распределение тем в тренажёре укрупнённое и не покрывает всю программу. Вопросы и тренировочную шкалу оценивания необходимо проверить учителю химии до публикации для учеников.


При подборе разделов использованы как ориентиры федеральные рабочие программы на ЕДСОО: [8–9 классы, базовый уровень](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_himiya_8-9_baza.pdf), [10–11 классы, базовый уровень](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_himiya_10_11_baz.pdf). Формулировки вопросов авторские, официальными экзаменационными заданиями не являются.

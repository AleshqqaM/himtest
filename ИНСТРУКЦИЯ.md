# ХимТест: инструкция для учителя

Сайт: https://aleshqqam.github.io/himtest/
Страница учителя: https://aleshqqam.github.io/himtest/teacher.html

Всё делается в браузере на github.com: ничего не нужно устанавливать и не нужно программировать. После каждого сохранения сайт обновляется сам примерно за 1–2 минуты.

> **Важно: репозиторий публичный.** Всё, что лежит в репозитории, может прочитать кто угодно. Не пишите в файлы имена учеников, оценки, телефоны и другие личные данные. Сайт устроен так, что они ему и не нужны.

## 1. Что где лежит

| Что | Где |
|---|---|
| Список конспектов (название, класс, порядок) | `content/materials.json` |
| Текст каждого конспекта | `content/materials/<id>.md` |
| Картинки к конспектам | `content/images/` |
| Тесты по темам | `data/topics.json` и `data/questions/` (как их править — в `README.md`) |

Каждый конспект состоит из **двух частей**: записи в списке `materials.json` и файла с текстом `.md`. Имя файла совпадает с `id` записи. Например, у записи `"id": "g8-salts"` файл называется `content/materials/g8-salts.md`.

## 2. Как добавить конспект

### Шаг 1. Придумать id

`id` — короткое имя конспекта латиницей. Его видно в ссылках-планах, поэтому **после публикации его лучше не менять**.

- только строчные латинские буквы, цифры и дефис: `g8-salts`, `g9-metals-1`;
- без пробелов, русских букв и заглавных;
- удобно начинать с класса: `g8-…` — 8 класс.

### Шаг 2. Создать файл с текстом

1. Откройте репозиторий на github.com, зайдите в папку `content`, затем в `materials`.
2. Нажмите **Add file → Create new file**.
3. В поле имени напишите `g8-salts.md` (ваш id и `.md` на конце).
4. Напишите текст конспекта. Правила оформления — в разделе 3. Начинайте с заголовка `## …`.
5. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes** в окне.

### Шаг 3. Добавить запись в список

1. Откройте файл `content/materials.json` и нажмите карандаш **Edit this file**.
2. Скопируйте любую запись (от `{` до `}`) и вставьте её туда, где тема должна стоять в курсе. **Порядок записей внутри класса — это порядок курса:** по нему считаются кнопка «Дальше» и следующая тема, если её не задал учитель.
3. Поменяйте поля:

```json
  {
    "id": "g8-salts",
    "grade": 8,
    "title": "Соли",
    "summary": "Состав и названия солей, растворимость и первые реакции.",
    "file": "./content/materials/g8-salts.md",
    "test": "grade-8-compounds",
    "minutes": 10
  }
```

| Поле | Что писать | Обязательно |
|---|---|---|
| `id` | id из шага 1 | да |
| `grade` | класс числом от 6 до 11, **без кавычек** | да |
| `title` | название темы | да |
| `summary` | одна-две фразы: о чём конспект | да |
| `file` | `./content/materials/` + id + `.md` | да |
| `test` | тест «Проверь себя» после чтения, список ниже | нет, строку можно удалить |
| `minutes` | сколько минут читать, числом без кавычек | нет, строку можно удалить |

4. Проверьте запятые: **между записями `}` и `{` нужна запятая, после последней записи — нет**. Внутри записи запятая стоит после каждой строки, кроме последней.
5. Нажмите **Commit changes…** → **Commit changes**.

### Шаг 4. Проверить на сайте

1. Через 1–2 минуты откройте сайт и обновите страницу. Если всё ещё старая версия, подождите. На вкладке **Actions** в репозитории видно, закончилось ли обновление: там появится зелёная галочка.
2. Нажмите «База знаний», выберите класс и откройте новый конспект.

**Если карточка «База знаний» пропала с главной или раздел пишет об ошибке**, значит, в `materials.json` опечатка. Обычно это лишняя или пропущенная запятая, кавычка или скобка. Ещё бывает, что `file` не совпадает с `id` или `test` указан с ошибкой. Откройте файл, найдите ошибку и сохраните ещё раз. Тесты и остальной сайт при этом продолжают работать.

## 3. Как оформлять текст конспекта

| Пишете | Получается |
|---|---|
| `## Заголовок` | крупный заголовок раздела |
| `### Подзаголовок` | заголовок поменьше |
| пустая строка | новый абзац |
| `- пункт` | список с точками |
| `1. пункт` | нумерованный список |
| `**важно**` | **жирный** текст |
| `*термин*` | *курсив* |
| `> Запомни: …` | выделенный блок «Запомни» |
| `H~2~SO~4~` | H₂SO₄: нижний индекс |
| `Fe^3+^`, `SO~4~^2−^` | Fe³⁺, SO₄²⁻: верхний индекс |
| `[учебник](https://example.org/page)` | ссылка (только `https://`) |
| `![Схема опыта](./content/images/g8-salts-1.png)` | картинка |

Пример:

```markdown
## Что такое соль

**Соль** — сложное вещество из катионов металла и анионов кислотного остатка.

- NaCl — хлорид натрия
- CuSO~4~ — сульфат меди(II)

> Запомни: растворимость солей проверяй по таблице растворимости.
```

Ограничения:

- HTML-теги не работают и показываются как обычный текст. Так задумано, чтобы ничего не сломалось.
- Индекс пишется без пробелов внутри: `~2~` и `^3+^`.
- Таблиц пока нет. Если таблица нужна, вставьте её картинкой.

## 4. Как добавить картинку

1. Подготовьте картинку в формате PNG, JPG или WEBP, лучше меньше 300 КБ. Назовите её латиницей без пробелов: `g8-salts-1.png`.
2. Зайдите в папку `content/images`, нажмите **Add file → Upload files**, перетащите файл и нажмите **Commit changes**.
3. В тексте конспекта напишите `![Короткое описание картинки](./content/images/g8-salts-1.png)`. Описание нужно для слабовидящих учеников и на случай, если картинка не загрузится.

Картинки с других сайтов не показываются: только из `content/images`.

## 5. Как исправить или убрать конспект

- **Исправить текст:** откройте `.md`-файл, нажмите карандаш, поправьте и сохраните.
- **Поменять порядок:** в `materials.json` перенесите запись целиком на новое место, следя за запятыми.
- **Убрать конспект:** удалите запись из `materials.json` и сам `.md`-файл. Файл удаляется так: откройте его, нажмите **⋯** справа сверху, затем **Delete file**. Удаляйте обе части: если оставить запись без файла, конспект в разделе останется, но не откроется. У учеников, в чьих планах была эта тема, план не сломается: сайт напишет, что части тем пока нет на сайте.

## 6. Как выдать план ученику

План — это ссылка. В ней записаны пройденные темы, следующая тема и дата. Имени в ссылке нет, на сайте ничего не сохраняется.

1. Откройте https://aleshqqam.github.io/himtest/teacher.html (ещё туда ведёт ссылка «Для учителя» внизу сайта).
2. Отметьте **«Пройдено»** у тем, которые разобрали с учеником.
3. Отметьте **«Следующая»** у одной темы, с которой ему продолжить. Можно не задавать: тогда сайт предложит следующую тему по порядку курса.
4. Проверьте дату (по умолчанию сегодняшняя).
5. Нажмите **«Скопировать»** и отправьте ссылку ученику в мессенджере. С телефона удобнее кнопка **«Поделиться»**.

Кнопка «Открыть как ученик» показывает, что увидит ученик.

### Что видит ученик

1. Открывает ссылку. Сайт предлагает «Сохранить план в кабинет?».
2. После сохранения в кабинете появляется блок «Мой план»: следующая тема с кнопкой «Читать» и список пройденного. На главной появляется кнопка «Читать тему».
3. В конспекте ученик отмечает «Прочитано» (+10 опыта) и может сразу пройти тест.

План хранится только в браузере ученика. Если ученик откроет ссылку на другом телефоне или очистит данные браузера, ссылку нужно открыть заново.

### Как обновить план после следующего занятия

1. На странице учителя вставьте **прежнюю ссылку** этого ученика в поле «Изменить прежний план» и нажмите **«Подставить»**.
2. Добавьте новые пройденные темы, выберите новую следующую и поправьте дату.
3. Скопируйте и отправьте новую ссылку. У ученика она заменит старый план.

### Как не перепутать учеников

Сайт не знает, кто есть кто. Храните последнюю ссылку каждого ученика у себя, например в заметках телефона: «Маша, 8Б — ссылка». Сама переписка в мессенджере тоже подходит как такой список. На сайт и в репозиторий имена не вносите.

## 7. Если что-то пошло не так

- **Сайт не обновился.** Подождите пару минут и обновите страницу. Проверьте вкладку **Actions**: обновление должно закончиться зелёной галочкой.
- **Сломалось после правки.** В репозитории откройте файл и нажмите **History**: там видна каждая правка, и можно посмотреть, что изменилось. Проще всего вернуть файлу прежний вид: скопировать текст из прошлой версии и сохранить заново.
- **Ученик пишет «Ссылка на план повреждена».** Обычно ссылка обрезалась при копировании. Отправьте её ещё раз целиком.
